# Secrets

Encrypted secrets live beside the services that use them, in `secrets/*.yaml`. Their contents and Argo root ownership were preserved during the source reorganization.

| Location | Purpose |
| --- | --- |
| `talos/talsecret.sops.yaml` | Encrypted Talos cluster secrets |
| `kubernetes/services/<service>/secrets/` | Service credentials |
| `kubernetes/platform/<capability>/.../secrets/` | Platform credentials |
| `kubernetes/.sops.yaml`, `talos/.sops.yaml` | Public age recipients and encryption rules |

Each service's `owner` selects `apps-secrets` or `infra-secrets`. Those roots render the source chart in `secrets` mode, copying encrypted manifests unchanged, even for disabled services. sops-secrets-operator decrypts SopsSecrets into Kubernetes Secrets. Secret enablement is intentionally independent of workload enablement.

Edit using SOPS and the repository's age key:

```sh
cd kubernetes
sops services/n8n/secrets/n8n-secrets.yaml
```

For a new file, follow an existing SopsSecret's shape and keep Kubernetes metadata readable. Encrypt secret payloads before staging and inspect the staged diff. Never commit private age keys, generated machine configs, kubeconfigs, or decrypted copies.

`.envrc` selects `~/.config/sops/age/cluster-config.txt` and a repository-generated kubeconfig. The current operator session may instead use the configured `admin@cluster` context; do not replace a working kubeconfig with a nonexistent generated file merely to edit a secret.

## Outside Git

- The private age key is supplied by the operator. `just deploy-age-key` supplies it to sops-secrets-operator.
- Pocket ID's bootstrap API token is a manually supplied regular Secret. See [Pocket ID](../kubernetes/platform/identity/pocket-id/README.md).
- OIDC client credentials and CNPG database credentials are generated by their respective controllers/jobs.
- Application data and first-user enrollment generally live on persistent volumes and require separate backups.

The managed CA manifest is [cert-manager/secrets/home-root-ca.yaml](../kubernetes/platform/identity/cert-manager/secrets/home-root-ca.yaml). An old copy is retained under `cert-manager/reference/`; Helm excludes that directory, so it is not added to the managed resource set.

A Git archive does not replace data backups or private-key recovery. See [backup status](backup-manual.md).
